SYNTHETIC REFERENCE · ONE SIMPLE DOOR

A MyoHand-derived skeleton, compliant contact envelopes and a floating body run in native MuJoCo. An authored reach and arm controller combines with eight finger corrections selected through 64 simulated policy-search trials. Real door-opening footage guided the grasp. This is an engineered simulation, not captured human ground truth or a validated biomechanical model. A collision-checked arm release and a joint-torque walking controller complete the sequence. An explicit posture cost penalizes torso tilt and backward lean. The cautious gait is a first physical reference; human style and retargeting still need validation.

The previous v2 recording was rejected because the thumb did not touch the lever. The corrected v3 grasp is preserved in this v4 full sequence, with posture, planted-foot slip and complete portal-clearance checks added.
