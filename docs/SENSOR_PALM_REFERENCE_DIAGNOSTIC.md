# Rejected ground-frame palm correction

The opt-in `sensor_palm_reference.py` candidate is **not admitted for physical execution**. The unchanged native acquisition and corrected-passive Isaac acquisition recordings were screened through a detached robot/scene calculator. Native geometry passed; Isaac geometry introduced premature little-finger contacts and failed. Existing acquisition results remain unchanged.

The proposal projects the canonical palm path offline into the initial pelvis yaw/XY gauge while retaining its original ground height, 0.870679927 m. It does not replace that height with the foot-derived estimator's approximately 0.872416 m calibration. Runtime uses only the previous decision's existing sensor-derived root estimate, current encoders, and static joint/palm goals. It calls the base force controller once, preserves original motor caps and command history, and modifies seven right-arm/wrist targets only. Bounds are 10 mm translation, 50 mrad rotation and joint correction, 0.25 rad/s correction slew, and original total goal/physical limits.

All 9,500 decisions in both recordings passed bounded IK and goal-rate screening. Collision checks sampled every 20 ms before 14 s and every 2 ms thereafter, under both measured-arm-plus-correction and corrected-command interpretations. Native had no rejected geometry; Isaac had 5,024 rejected samples. The first new invalid little-finger distal contact appeared at 13.740 s, when the original pose remained clear. At 15 s, correction introduced approximately 2.20 mm little-finger middle-phalanx overlap. Staying below the separate 3 mm penetration limit does not make that contact anatomically valid.

The recorded estimator differs from actual root orientation/position by several milliradians/millimeters. At 17 s, estimated minus actual local XY is approximately [-2.43, +2.75] mm. The attempted correction consequently moves the actual palm 1–3 mm below the intended ground path while leaving lateral error. A better state-estimation prerequisite must be demonstrated before executing this candidate. Common horizontal foot translation is not directly observable through the fixed-foot-position assumption.

Reproduction uses `scripts/dexterous/screen_sensor_palm_reference.py --robot XML --door DOOR_DIRECTORY --reference REFERENCE_JSON --native NATIVE_ARCHIVE --isaac ISAAC_ARCHIVE --output NEW_DIRECTORY`. No simulator steps are permitted by the screen. The [receipt](evidence/rejected-palm-reference-001.json) binds the original sources, numerical screen, and failed geometry. Local candidate sources have additional schema/rotation/time validation tested in `tests/test_sensor_palm_reference.py`; these checks do not alter the original recorded result.
